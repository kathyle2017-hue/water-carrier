# Godot 2D, one 3/4 view, English UI

Version 1 is a Godot **2D** game, **desktop first**. One camera language for every walk: **3/4**, **16×16** tiles, the **water-carrier** drawn a step taller so the face reads. Not a side-scroller **water run**, not a second walk cycle, not straight top-down as the first pass.

Player-facing text is English. Domain words with no honest English stay Vietnamese (**đòn gánh**, **quán**, **Huế**, kinship). Not a Vietnamese-only UI for version 1, and not a translation that lies.

Placeholder pixels ship the loop. Intro art and a new character sheet can drop in later without changing **Fill** / **Unload**.

**Status:** accepted
